# 鱼骨头英语复习系统

> 把英语啃的只剩鱼骨头。

把自己的试题、单词、听力材料放进同一个学习空间，完成练习、整理错题、复习闪卡，并记录每天的学习进度。

**[在线使用](https://yuanxuru-oss.github.io/English-systems/review-system/)** · **[下载 Windows 桌面版](https://github.com/yuanxuru-oss/English-systems/releases)**

桌面版下载 `review_atelier.exe` 后即可直接打开。在线版和桌面版均支持本地保存学习数据。

## 适合谁使用

- 想把 CET、课程英语或其他英语考试资料整理到一个系统中的学习者。
- 有阅读、听力、翻译、词汇资料，但不希望每次都手动整理错题和单词的人。
- 希望离线保存个人复习记录，并随时导出备份的人。

## 开始前选择版本

| 版本 | 适合场景 | 打开方式 | 数据保存位置 |
| --- | --- | --- | --- |
| 在线版 | 希望随时在浏览器打开 | 点击上方「在线使用」 | 当前浏览器 |
| Windows 桌面版 | 希望固定在电脑上、离线使用 | 从 Releases 下载 `review_atelier.exe` | 当前电脑的桌面应用 |

两种版本功能相近，但数据**不会自动同步**。需要切换版本或更换设备时，请使用「设置」中的导出与导入功能。

## 首次使用

1. 打开系统，在登录页输入名字并进入学习空间。
2. 新用户会得到一个空的「我的英语复习」项目和「第一份复习资料」文件夹，不会看到其他人的试题。
3. 点击右上角的 `?`，可随时重新打开四步使用帮助。
4. 进入「导入中心」，添加自己的第一份练习内容。

> 名字用于区分这台设备上的本地学习空间，不是网络账号，也不会自动上传。

## 导入自己的资料

进入「导入中心」后，先选择题型，再把资料粘贴到编辑区，依次点击「生成预览」和「加入当前项目」。导入成功后，内容会进入当前试卷文件夹。

### 支持的内容

| 类型 | 用途 | 可附加内容 |
| --- | --- | --- |
| 阅读填空 | 完型、选词填空、句子填空 | 文章、题干和答案 |
| 阅读原题 | 阅读理解选择题 | 文章、选项和正确答案 |
| 精听填空 | 原文挖空精听 | 听力原文、MP3 或 WAV 音频 |
| 听力原题 | 听力选择题 | 原文、选项、MP3 或 WAV 音频 |
| 词汇表 | 生词整理和闪卡复习 | 单词、词性、释义、例句 |
| 翻译练习 | 中译英练习 | 中文原句和参考译文 |

### 手动导入步骤

1. 在「导入中心」选择对应题型。
2. 保留页面给出的模板格式，只替换为自己的内容。
3. 听力内容如有音频，点击「选择音频文件」，上传 MP3 或 WAV 文件。
4. 点击「生成预览」，检查题目、答案、选项和文章是否正确。
5. 点击「加入当前项目」。

### 最小模板示例

**阅读填空**

```text
[模块类型] reading
[标题] Unit 1 阅读填空
[文章]
Learning a language requires patience and regular practice.
[题目]
requires ____ | patience
regular ____ | practice
```

**词汇表**

```text
[模块类型] vocabulary
[标题] Unit 1 核心词汇
[词汇表]
patience | n. | 耐心 | Patience helps learners make steady progress.
regular | adj. | 有规律的 | Regular review makes memory stronger.
```

**翻译练习**

```text
[模块类型] translation
[标题] Unit 1 中译英
[题目]
坚持练习能让学习更稳定。 | Regular practice makes learning more consistent.
```

> 导入后仍可继续在项目中创建新试卷文件夹、调整文件夹名称，并把不同套题分开管理。

## 功能说明

### 首页

- 查看今日是否完成打卡、连续学习天数、本周完成次数和待巩固内容。
- 使用「继续学习」回到当前项目，或使用「导入内容」加入新资料。
- 首页下方的学习路径帮助你按「导入 → 练习 → 错题 → 闪卡」完成一次复习闭环。

### 项目总览

- 用项目和试卷文件夹整理不同考试、课程或复习计划。
- 可新建、重命名和删除试卷文件夹。
- 每个文件夹会展示阅读、听力、词汇和翻译模块的数量。

### 听力练习

- 支持播放已导入的 MP3 或 WAV 音频。
- 可完成听力填空或听力选择题。
- 精听模式可结合原文进行挖空练习；重点词高亮放在精听阶段，避免影响第一次听题。

### 阅读与翻译练习

- 阅读模块支持填空和选择题练习。
- 翻译模块支持输入自己的译文，并与参考表达进行核对。
- 提交后，错误或待复习内容会进入错题回收流程。

### 词汇表、闪卡与错题笔记

- 词汇表可标记是否掌握，并加入闪卡词库。
- 闪卡通过翻转卡片帮助重复记忆。
- 错题笔记集中展示错误记录，可补充复盘笔记、标记掌握，或加入闪卡再次巩固。

### 打卡日历与个人中心

- 每完成一项学习动作，系统会记录当日学习情况。
- 打卡日历用于查看每日完成情况和连续学习记录。
- 个人中心汇总学习天数、练习动作、错题和闪卡掌握情况。

### 主题与随手笔记

- 在「设置」中选择基础色、暗夜、森林绿、海洋蓝或樱花粉主题。
- 可使用 `Ctrl + Shift + N` 打开随手笔记，记录临时想法。

## 推荐复习流程

1. **建立资料夹**：按考试或课程新建试卷文件夹，例如「CET-4 真题 2025 年 6 月」。
2. **导入内容**：先导入一篇阅读、一个听力原文或一组词汇即可，不必一次整理完所有资料。
3. **完成练习**：从阅读、听力或翻译中选一项开始，完成后系统会记录学习动作。
4. **处理薄弱点**：将错题写进错题笔记，把生词加入闪卡。
5. **短时复习**：每天打开首页，优先处理待巩固的错题和闪卡。
6. **定期备份**：每周或在大批量导入资料后导出一次 JSON 数据。

## AI 翻译

右下角的「翻译器」可查询单词、短语或短句。页面内已有的词汇会优先从本地词库读取；未命中时可使用 AI 翻译辅助。

### 使用步骤

1. 进入「设置」的「AI 学习辅助」。
2. 开启「启用 AI 翻译辅助」和「显示 AI 翻译浮窗按钮」。
3. 选择可用的 AI 服务方式并完成配置。
4. 点击右下角「翻译器」，输入单词或短句，点击「查询翻译」。

在线版推荐使用「免费额度」；若使用自定义 AI 服务，请只在自己的设备中保存 API Key，不要提交到 GitHub 或公开截图。

> 「AI 导入」入口用于将原题文本整理为练习草稿。目前应先检查并确认草稿内容后再导入；重要试题请保留原始文件备份。

## 数据备份与迁移

学习资料、练习记录、错题和闪卡默认只保存在当前设备。

### 导出数据

1. 打开「设置」或「个人资料」。
2. 点击「导出数据 (JSON)」或「导出学习数据」。
3. 将下载的 JSON 文件保存在安全的位置。

### 导入数据

1. 在新浏览器或新设备登录自己的学习空间。
2. 打开「设置」。
3. 点击「导入数据 (JSON)」，选择之前导出的 JSON 文件。
4. 确认覆盖当前数据后，刷新页面即可恢复。

### 请注意

- 清除浏览器数据、使用浏览器清理工具或卸载桌面版前，务必先导出备份。
- 在线版和桌面版的数据彼此独立，迁移时需要手动导出再导入。
- 退出登录不会删除学习数据；清除本地数据只会影响当前学习空间。

## 常见问题

**在线版打不开或没有显示最新内容？**

先使用 `Ctrl + F5` 强制刷新；仍未更新时，尝试无痕窗口。GitHub Pages 发布后可能需要等待几分钟。

**我可以导入 CET 真题吗？**

可以。将题目按导入中心模板整理即可。听力题可加入原文和 MP3/WAV 音频，阅读题可加入文章、选项和正确答案。

**导入后为什么找不到内容？**

请确认导入前选中的「当前项目」和试卷文件夹。回到「项目总览」展开对应文件夹，即可查看已加入的模块。

**听力没有声音怎么办？**

确认导入时已选择音频文件，并使用 MP3 或 WAV 格式。浏览器可能要求先点击播放按钮后才允许播放声音。

**AI 翻译没有结果怎么办？**

检查设置中是否开启 AI 翻译辅助、当前服务是否可用，以及网络是否正常。若使用自定义服务，请确认接口地址、模型和 Key 有效；不要在公开环境泄露 Key。

**桌面版被 Windows 提示风险？**

桌面版为未签名的个人发布应用，Windows 可能显示安全提示。请只从本仓库的 Releases 页面下载，并确认版本号与发布记录一致。
